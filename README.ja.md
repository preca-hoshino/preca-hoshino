## 概要

- 上海大学にて自動化（Automation）を専攻。
- <b>SHUOSC</b>（上海大学オープンソースコミュニティ）のメンバー。オープンソースのエコシステムを信奉しています。
- <b>テクニカルアート</b>（Technical Art）に必要な技術を習得中 —— シェーダープログラミング、PBR / NPR レンダリング、プロシージャルコンテンツ生成（PCG）。
- <i>プロジェクトセカイ カラフルステージ！ feat. 初音ミク</i>、<i>アークナイツ</i>、<i>アークナイツ：エンドフィールド</i> の古参ファン。`:)`
